# Andre Jimm Campilan — Portfolio

A responsive, lightweight portfolio website showcasing AHDIS and RBIM, developed in the context of work at the Commission on Population and Development – Region X.

## Run locally

Open `index.html` in a modern browser, or run `python -m http.server 8000` in this directory and visit http://localhost:8000.

## Deploy to Vercel

**Option 1 (recommended):** Create a new GitHub repository, upload these project files (including the `assets` folder), then in https://vercel.com/new import that repository. Select framework **Other**, and deploy. No build command or environment variables required.

**Option 2 (CLI):** Install Node.js, run `npx vercel` from this directory to deploy a preview, then `npx vercel --prod` to publish.

## Customize before sharing with employers

- Update the name, email and current role in `index.html`.
- Review the screenshots to ensure no protected agency records, identifying information, or confidential dashboards should be public.
- Confirm that CPD Region X allows showcasing these application screenshots, branding, and descriptions.
- Add independently verified technologies and your exact individual responsibilities. Do not claim features or tools you did not personally implement.
- Consider adding a resume PDF and links to your public GitHub/LinkedIn profiles.

This site is static and has no login, database connection, or public access to AHDIS or RBIM systems.
